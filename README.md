# AXIOM-9 | Cyborg-Themed Landing Page

A responsive, cyborg-themed landing page built with plain HTML, CSS and JavaScript. No frameworks, no build step.

**Theme:** *Human, Upgraded.* A futuristic cyberpunk UI with neon cyan / magenta / lime accents, HUD elements and glitch effects.

## Features

- Glitch-effect hero heading and animated typing terminal
- Animated SVG cyborg-eye HUD with rotating rings
- Circuit / particle network background (HTML canvas)
- Animated stat counters and scroll-reveal sections
- Core systems cards with hover scan effect
- Interactive augmentation scanner (tabs with animated stat bars)
- Evolution timeline and waitlist form
- Fully responsive (desktop, tablet, mobile) with hamburger menu
- Respects `prefers-reduced-motion`

## Tech Stack

- HTML5, CSS3 (custom properties, grid, flexbox, clip-path, keyframes)
- Vanilla JavaScript (Canvas API, IntersectionObserver)
- Google Fonts: Orbitron, Rajdhani, Share Tech Mono

## Run Locally

1. Clone the repo
   ```
   git clone https://github.com/sweta-y/cyborg-landing-page.git
   ```
2. Open `index.html` in any modern browser (internet needed for fonts).
